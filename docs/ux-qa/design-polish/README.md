# Design polish review

Working files for the design polish review on PR #52, saved here so a container restart loses
nothing. `round-N/` holds each round's capture manifests, drift tables, reviews and plan;
`ledger.json` tracks every finding and its status; `tools/` holds the capture scripts (rerun with
`ROUND=N`) and `archive.sh`, which copies a round here; `workflow.js` is the review loop. The
screenshots stay in the session scratchpad. The round summaries are in `../ux-qa-review.md` under
"Design polish review".
